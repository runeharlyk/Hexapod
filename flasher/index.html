Board: ESP32-S3 WROOM with camera (ESP32-S3-EYE pinout).

Your browser does not support Web Serial. Use Chrome or Edge on a desktop. Web Serial needs this page to be served over HTTPS.

No firmware has been published yet. Build from source as described in the getting started guide.

Before you start
  • Connect the board over the native USB port with a data cable.
  • The board needs 16 MB of flash; the image carries the 16 MB partition table.
  • A first install erases the board, including saved settings.
After installing
  1. Join the Wi-Fi network Hexapod-XXXXXX with password hexapod1.
  2. Open http://192.168.4.1 and configure your home network under Wi-Fi.
